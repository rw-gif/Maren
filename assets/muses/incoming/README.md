# Drop zone — muse shots (incoming)

Upload the raw muse photography here, then I'll optimise, rename and move
each file into its final home. **Don't worry about names or sizes** — drop
them as-is (the generic `IMG_xxxx.jpg` names are fine).

## How to upload (no local git needed)

GitHub web → the `rw-gif/maren` repo → **Add file → Upload files** →
drag the images into this folder → **Commit** to the branch
`claude/maren-storefront-build-6ywgx2`.

## What happens next

1. I review every image and build a **mapping table**: which product +
   colour each on-model shot belongs to, which are lookbook looks, and which
   go into the general collateral pool (hero / journal / films / World).
2. You confirm the table.
3. I batch-compress to web sizes and sort them into:
   - `assets/muses/edit/`  — on-model shots → card hover image + PDP gallery
   - `assets/muses/looks/` — shoppable lookbook looks (I place the `+` hotspots)
   - `assets/muses/lib/`   — shared collateral pool
4. I wire them into the site, verify headless, and push. This `incoming/`
   folder is then emptied.

Heavy originals never ship — only the optimised, sorted copies are referenced.
