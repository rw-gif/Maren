# Product imagery

Drop product photos here and they appear automatically across the site — on
the cards, the product quick-view (PDP), the cart, the lookbook row and search
results. Until a file exists, the monogram "M" placeholder holds the space, so
the site never looks broken.

## Filenames

Use the product **id** (from `assets/js/app.js` → `products`):

| id | Product | Main image |
|---|---|---|
| `shift` | The Linen Shift | `shift.jpg` |
| `breton` | Breton Long-Sleeve | `breton.jpg` |
| `set` | Gingham Boxer Set | `set.jpg` |
| `pj` | The Sea Pyjama | `pj.jpg` |
| `babydoll` | Babydoll Mini | `babydoll.jpg` |
| `knit` | Cable Cardigan | `knit.jpg` |
| `shirt` | Coastal Oversize Shirt | `shirt.jpg` |
| `scallop` | Scallop Linen Mini | `scallop.jpg` |

Optional gallery shots: `shift-2.jpg`, `shift-3.jpg`, etc. (hook is in place;
the PDP currently shows the main image).

## Guidance
- Portrait works best (cards crop ~3:4, PDP ~3:4). ~1200px wide is plenty.
- Keep them web-optimised (JPG/WebP, compressed) for fast loading.
